# 移动工作台实施计划

1. 开发前读取相关 Trellis 前端／浏览器规范，复核 `09-16` 的任务状态和已合入改动，建立无冲突的 CSS／模板修改清单。
2. 实现移动 shell、顶栏、底栏、返回路径和共享卡片／sheet 基元。
3. 先完成首页、账单、流水三个高频页，再完成对象层级与实体详情，最后完成更多内的催收、现金、支出、银行和租住安排。
4. 将强确认、URL 输入、同步和错误状态接到页面数据任务的真实 action contract，不复制业务校验到 JavaScript。
5. 在 360／390／430／600px 用真实浏览器逐项操作和截图；回归 1366px 桌面后交给父任务集成验收。
