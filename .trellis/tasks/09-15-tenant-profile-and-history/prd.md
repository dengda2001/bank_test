# 租客档案、付款人关系与缴费历史

## 目标

让房东可维护可联系、可辨识的租客档案，并在独立详情页按期间查看每月账单和所有有效收款来源；同时安全表达租期、停用和提前退租对未来账单的影响。

## 范围

- 租客资料新增／迁移显示别名、邮箱、房间名称与地址文本；列表以别名优先并同时显示正式姓名和房间。别名不参与任何自动银行匹配。
- 新建租客时计费开始日默认租期开始日；允许在高级设置延后，且必须落在租期内。编辑既有资料不得因默认值覆盖已保存日期。
- 管理一对多银行付款人关系：稳定付款人 ID 优先，缺失时使用标准化精确姓名；保留原始值、来源、建立时间和最近匹配时间。允许移除关系但不改写历史收款。
- 识别共享／冲突付款人，禁止其成为自动选中租客的依据；仅维护候选关系，不在本任务实现自动匹配或历史批量处理。
- 提供独立租客缴费详情、期间筛选和分页；每月显示应缴日、应收、实收、未收、缴费状态和有效银行／现金收款明细。没有收款的适用账单必须可见。
- 应用整月计费、当前租金不改写已生成账单、补建旧月标记“历史租金待核对”的一期限制。
- 生命周期：结束日期所在月仍适用；之后不生成新账单。停用仅阻止新账单；提前结束时无有效收款的未来账单作废，有有效银行或现金收款的受影响账单必须阻止保存并引导先更正。
- 保持房间为当前租客文本。历史详情不得声称房间文本是发生时的房间快照。
- 一期租客账单币种固定为 EUR；保留现有三位币种字段以便将来扩展，不在资料页提供换汇或多币种汇总。

## 不在本任务中

- 银行入账用途、记住付款人后的自动判定、匹配或拆分（子任务 3）。
- 现金补录／作废操作（子任务 4）；本任务只展示账本已存在的有效记录。
- Dashboard 的全月汇总和催缴。
- 独立房间、租约文档、租金版本、换房历史。

## 验收标准

- [ ] 新建、编辑和重新打开租客后姓名、别名、邮箱、房租、应缴日、租期、计费开始日及房间文本正确；邮箱和日期关系有字段级提示。
- [ ] 一个租客可维护多个付款人；共享身份被明确标记，移除关系不删除或改写已确认流水和历史账单。
- [ ] 在租客详情选择超过三个月的期间时，每个适用月至多一张有效账单，零收款月份也可见；同月多笔有效收款正确汇总并可展开。
- [ ] 已生成账单的应收不因修改当前月租而变化；未生成的旧月若按当前月租生成则明确显示历史租金待核对。
- [ ] 提前退租只能作废无有效收款的结束月之后未来账单；有收款时整次保存失败且不部分作废。退租／停用不隐藏既有欠款与历史。
- [ ] 所有资料、付款人关系、账单和历史详情均按当前用户隔离。
- [ ] 非 EUR 的租客账单输入被明确拒绝；已有币种字段和接口边界保留，不将非 EUR 金额静默换算为 EUR。
