# 页面数据与路由实施计划

1. 开发前读取领域子任务的最终契约和项目规范；为旧路由建立兼容测试基线。
2. 添加规范 GET 路由、URL 保留规则和按用户范围的加载器。
3. 逐页建立 view model：先总览／账单／流水，再催收／资产／租住安排，最后现金／支出／银行。
4. 接入所有需要预览或强确认的 POST 流程，并写 handler／权限／错误状态测试。
5. 交付样式无关的模板数据或 render contract，供桌面任务实现；在桌面任务稳定后供移动任务消费。

## 验证

```sh
go test ./cmd/truelayer-demo/...
go test ./...
```

至少用隔离的两个用户测试任一资产、账单、流水、支出和银行操作的越权路径。
