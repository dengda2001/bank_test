# 桌面工作台设计

## 布局契约

页面采用 236px 左侧深色导航、64px 顶栏和可滚动内容工作区。共享 token 使用原型的浅冷背景、白色 surface、深蓝文字和绿色主动作；金额使用等宽数字，状态通过文本、图标／点与颜色共同表达。

## 页面构成

- 总览为四指标、待处理事项和房产→房间→租客表格／树。
- 账单、流水、催收用高密度表格，行点击打开详情或进入确认流。
- 房产、房间、租客、租住安排、现金、支出和银行使用列表＋详情结构；创建／编辑使用侧抽屉。
- 房产／房间／租客／流水详情采用原型的指标、事实列表、时间线和关联记录。每一处数值来自页面数据任务，不能复制样例数字。

## 强交互

人工平账为“输入原因 → 审核影响 → 确认”；催收为“候选 → 邮件预览 → 发送确认”；停用需要显示阻断原因。发票区域仅为外链文本输入和打开链接。

## 与移动的边界

本任务交付语义类名、token 和可访问交互契约。DOM 不假定手机可以显示同一张宽表；移动任务可在同一数据字段上换成卡片和 sheet。
