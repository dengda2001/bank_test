# Login visual alignment

## Goal

Make the password login page look like the RentOps workspace it opens.

## Requirements

- Use the workspace's green accent, typography, surfaces, borders, button, focus, and error styles on the login page at desktop and mobile widths.
- Keep username/password POST behavior, error handling, keyboard access, and autocomplete intact.
- Replace implementation-facing login help text with user-facing wording.

## Acceptance Criteria

- [ ] Login and workspace share a recognizable visual system on desktop and mobile.
- [ ] Username/password entry, Enter submission, invalid-credential feedback, focus visibility, and browser autofill remain usable.
- [ ] The page does not expose environment variable names as product instructions.

## Dependency

None. This is an independently verifiable visual change.
