# 桌面工作台实施计划

1. 开发前读取页面数据任务的接口、现有移动任务的改动和前端规范，确认不覆盖其他未提交模板／CSS。
2. 建立共享桌面 token、shell、导航和交互基础件，先用总览验证，再扩展全页。
3. 依次完成总览／账单／流水／催收，再完成资产与租客，再完成现金／支出／银行和只读租住安排。
4. 为详情抽屉、表单、确认层实现焦点、键盘、错误和空状态；将原型示意 action 接到真实 POST flow。
5. 用真实浏览器在 1366×768 和 1440×900 验收，记录截图和失败修复；完成渲染回归测试后交接移动任务。

## 验证

```sh
go test ./cmd/truelayer-demo/...
go test ./...
```

再运行真实浏览器的登录、资产创建、入住、同步、匹配、平账、催收和支出 URL 流程。
