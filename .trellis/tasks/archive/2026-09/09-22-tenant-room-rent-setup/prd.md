# 租客入住与房间租金设置

## Goal

让房东在新增租客时可以顺手设置入住关系与租金分担，并把房间的标准租金、起租月份和默认交租日提前收口到新增房间流程，减少保存后再进入其他页面补录的信息。

## User Value

- 新增租客时可直接选择房产和房间，不必再进入单独的入住/租金设置流程。
- 默认按房间内入住人数均分房间租金，同时允许为个别租客覆盖租金。
- 房间建立时即具备可用于自动收租的标准租金、租金生效月份和交租日。

## Requirements

- 仅在“新增租客”状态增加一个可选的入住设置区块；现有租客编辑页本次不承担换房或历史安排调整。
- 入住设置区块允许按“房产 → 房间”的顺序选择目标房间。
- 入住设置区块提供按月生效的入住月份，默认当前月份；这是现有租金计划时间线与已固化账务锁定所必需的边界。
- 选择房间后展示该房间的标准租金。
- 选择房间后自动加载目标生效月的已有租客及其当前分担金额。
- “当前新增租客”和“同房已有租客”分成两个清晰区块，避免把个人资料编辑与同住人分担调整混在一起。
- 已有租客区块整体采用弱化样式；姓名等身份信息只读，只允许编辑租金分担。
- 当前新增租客及已有租客的调整后租金均为可选输入，默认留空。
- 所有租金留空时，按该房间保存后的全部入住人数重新均分房间租金。
- 部分租客填写租金时，填写值视为固定分担，剩余房租由留空的入住人均分；全部填写时合计必须精确等于房间租金。
- 固定金额超过房间租金、剩余金额无法形成正数分担或最终金额不守恒时拒绝保存，并保留表单上下文。
- 租客租金输入框下展示表单提示“留空则按照入住人数均分房间租金”；该提示不可编辑，也不持久化。
- 不选择房产/房间时，仍可只创建租客，不创建入住与租金设置。
- 新增房间页增加必填的房间租金。
- 新增房间页增加租金生效月份选择，默认当前月份。
- 新增房间页增加默认交租日，默认每月 1 号。
- 新增房间页原“保存并设置入住与租金”按钮改为“保存并设置租客”。

## Confirmed Repository Facts

- 当前租金事实来源是按月版本化的 `room_rent_plans` 与 `room_rent_plan_members`，不再把租金写在 `rooms` 或 `tenants` 表上。
- 当前 `SaveRoomRentPlan` 要求至少一名租客，虽然数据库允许计划暂时没有成员；因此要支持“空房先保存租金”，需要放宽领域校验并确保空计划不会生成个人应收。
- 当前分担服务在所有成员金额未指定时会按稳定租客 ID 顺序均分余数；只要指定任一金额，就要求所有成员金额为正且总和严格等于房间租金。
- 当前新增房间只保存房间资料；“保存并设置入住与租金”会跳到房间详情的计划表单。本次需改为创建房间租金计划后跳到新增租客，并预选刚创建的房产／房间。
- 当前租客表单只保存人员和付款识别资料；历史上曾有房间与分担表单，但已在租金计划模型重构时移除，不能直接恢复旧字段或旧写入路径。
- 租金计划的生效月目前不允许早于都柏林时区的当前月份，符合本次默认当月的要求。
- 新增房间入口由房间列表和房产详情共用同一个抽屉模板；两条入口必须保持一致。

## Acceptance Criteria

- [ ] 新增租客时，不设置入住信息也能成功保存租客，行为与现有流程兼容。
- [ ] 新增租客时，选择房产后只能选择该房产下的房间，并能看到所选房间的标准租金。
- [ ] 新增租客的入住生效月份默认当前月；切换月份时，页面加载该月份有效的房间租金和已有租客，已被资金事实锁定的月份由后端拒绝改写。
- [ ] 新增租客时，选择房间后会在独立的弱化区块加载目标月份的已有租客；已有租客身份不可编辑，但租金可以调整。
- [ ] 新增租客时，所有租金留空会建立入住关系，并对包含新租客在内的全部入住人按稳定规则均分房间租金。
- [ ] 新增租客时，部分填写租金会固定已填金额，并把剩余房租均分给留空入住人；全部填写时严格校验合计等于房间租金。
- [ ] 页面在提交前展示分担合计／剩余金额，后端仍独立执行所有权、时间线和金额守恒校验。
- [ ] 新增租客入住区块在可选租金输入旁明确提示“留空则按照入住人数均分房间租金”，且不新增无意义的备注数据。
- [ ] 新增房间时，房间租金必填且需通过金额校验。
- [ ] 新增房间时，租金生效月份默认当前月，默认交租日为 1 号，并可修改为合法值。
- [ ] 新增房间保存后，房间标准租金及其生效月份、默认交租日可被后续入住/自动收租流程读取。
- [ ] 新增房间页按钮文案显示为“保存并设置租客”，并继续进入对应的租客设置流程。
- [ ] 相关后端、模板与浏览器验收测试覆盖新增字段、默认值、可选路径和主要错误路径。

## Out of Scope

- 重做已有租客、房间和租金列表页的整体布局。
- 改变历史账单或已生成租金事实的金额。
- 扩展新的租金分摊算法；本次仅支持默认按人头均分与手工覆盖单个租客租金。
