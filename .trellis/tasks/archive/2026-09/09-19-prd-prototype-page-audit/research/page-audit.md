# PRD 与原型页面全量差异审计

## 范围与方法

逐页对照 prdfile/prd.md、design.md、implement.md、桌面与移动 HTML 原型及其设计交接文件。按原型可见导航、详情、编辑、抽屉和空数据分支建立路由矩阵。浏览器使用本机 loopback 服务和一次性 rentops_audit 数据库，只创建一套合成房产、一间房间、一位租客；未触碰共享或生产数据。

实现页面在 1440×900、1366×768、390×844 三种视口逐路由复拍。另验证月份弹层边界、对象列表筛选、详情/编辑返回状态、空筛选结果和无房产账户的首页维度切换。原型金额只用于观察布局，不作为产品数据断言。

## 已修复并复核

- 默认首页即使没有结构化房产，也显示房产/房间/租客维度切换。
- 首页房产维度现可逐级展开房间和该房间本月租客责任；房间维度可展开租客责任。展开控件使用原生 details/summary，桌面表格和手机卡片分别排版。
- /bills 与 /dunning 使用各自页面，不再落到通用月度首页。
- 房产、房间列表支持搜索/状态/月度或房产筛选；移动端提供独立卡片布局和对象维度切换。
- 房产详情按原型补齐指标、房间概览、资料与关注区；房间详情补齐事实、收款和时间线区。
- 房产/房间新增与编辑使用右侧抽屉、手机底部 sheet；保存后保留月份和来源列表条件。
- 房产/房间详情返回链接保留原状态；通过浏览器分别验证房产搜索和房间的租客搜索、房产筛选、详情往返、编辑保存往返及空结果态。
- 树形列表通过 Go 模板生成合成房产数据，在 Chrome 1440×900 与 390×844 下逐级点击验证；房产→房间→两条租客责任和房间视角展开均成功，两个视口均无页面级横向溢出。
- 树形组装单元测试覆盖房产、房间及两条租客责任，并验证每条责任只归属到对应房间和房产；房间维度也返回相同租客责任。
- 修复租客编辑保存房间选择时只更新档案、未更新租约参与关系的问题；绑定/换房/解绑与档案更新放在同一事务，编辑页从当前有效租约回显房间，档案金额为空时用所选房间租金补默认值。已补充 opt-in MySQL 回归用例；本机未配置 `RENTOPS_MYSQL_TEST_DSN`，因此真实数据库断言尚未执行。
- 补齐交易详情状态 `/transactions?detail={id}`，详情按账户范围读取流水、分配、租金责任和操作记录；列表入口保留筛选/排序/页码，返回链接定位回原交易行。
- 手机底栏“更多”从 flyout 改为 `/more` 独立功能页，列出低频功能并保留导航高亮。
- 手机对象页共享网格产生的额外空白已消除；流水月份弹层在 1440 和 1366 宽度均留在视口内。
- 桌面/手机检查页都没有页面级横向溢出；房产/房间抽屉与手机底部详情操作可见。
- 本轮新增流水详情模板、列表链接、来源转义及分配归属断言通过；全量 Go 测试在允许 `httptest` 监听本机回环临时端口后通过，`go vet` 通过。
- 本轮“更多”与交易详情新 UI 尚未得到浏览器截图复核：in-app 浏览器启动报告当前环境缺少受信任的浏览器连接桥；模板测试不等同于视觉验收。

## 复核记录

- 1440×900：17 个有数据页面状态均返回 HTTP 200；首页各维度、房产/房间列表与详情/编辑、租客、账单、催收及流水均已截图。
- 1366×768：相同页面状态均返回 HTTP 200。
- 390×844：移动页面及空账户首页均返回 HTTP 200；房产/房间/租客列表和表单显示对象切换；房产与房间详情、编辑显示底部操作。
- 页面宽度：以上三种视口的页面级 scrollWidth 与 viewport 一致。
- 首页空账户：dashboardTabsVisible=true。
- /transactions 月份弹层：1440 下右边界分别 1123、1412；1366 下分别 1067、1338；均未超出视口。
- 房产/房间编辑流程保存后回到对应详情且月份仍为 2026-09；列表来源筛选的完整浏览器往返检查通过。
- 初次首页复拍有一条未能复现的浏览器 404 console 消息；单独监听首页网络响应没有再次出现 4xx/5xx。
- Go 检查：GOCACHE=/private/tmp/rentops-go-cache-audit go test ./cmd/truelayer-demo/... ./cmd/rentops-e2e/... 通过；git diff --check 通过。
- 树形列表复核截图：app-final-desktop-dashboard-tree.png、app-final-mobile-dashboard-tree.png。此次临时审计账号无结构化房产记录，因此这两张交互截图由同一嵌入 Go 模板和合成数据生成；临时文件未进入产品目录。
